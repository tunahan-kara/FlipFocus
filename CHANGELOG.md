# Changelog

## 1.0.0

- Added final split-flap app logo and Windows executable icon.
- Added Windows version/product metadata.
- X now fully exits by default.
- Added optional “keep running in tray when closed” preference.
- Esc continues to hide to tray.
- Added Pomodoro tray notifications.
- Reduced visible timer update frequency for lower CPU usage.
- Hidden stopwatch/clock updates stop when not needed.
- Hidden running Pomodoro uses a low-frequency background timer.
- Fixed normal-size restoration after leaving compact mode.
- Improved persisted window sizing behavior.
- Added icon generation, import checks and stricter packaging steps.

## 0.3.0

- Rebuilt the clock face as four independent digit cards.
- Added a more convincing two-stage split-flap hinge animation.
- Reduced empty transparent window space.
- Added a subtle seconds badge instead of a full-size seconds card.
- Improved control auto-hide behavior.
- Refined compact mode dimensions.
- Added configurable Pomodoro long-break interval.
- Improved tray quit/hide behavior.
- Added syntax checking to GitHub Actions before packaging.

## 0.2.0

- Added tray support.
- Added compact mode.
- Added Pomodoro long breaks and session tracking.
- Added automatic Windows builds with GitHub Actions.

## 0.1.0

- Initial clock, stopwatch and Pomodoro MVP.
